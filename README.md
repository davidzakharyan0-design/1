# Анализ каталога фильмов

Учебный проект на Python 3.12. Реализованы все девять этапов:
статистика, категории, циклы, строки, сортировка, словари,
множества, генераторы и итоговый отчёт.

## Подготовка

Необходим установленный uv.

```bash
uv sync
```

## Запуск отчёта

```bash
uv run catalog_analysis.py
```

## Проверка кода

```bash
uv run ruff check .
```

Данные находятся в catalog_analysis.py.
Используется стандартный модуль math.
Ruff установлен только как зависимость для разработки.
